# Security Policy

## Report a vulnerability

Use [Report a vulnerability](https://github.com/buildwithailab/workflow/security/advisories/new) to reach the Workflow maintainers privately. Keep vulnerability details out of public issues, pull requests, and comments. Use [GitHub Issues](https://github.com/buildwithailab/workflow/issues/new/choose) for ordinary bugs and feature requests.

Include the affected Workflow version or commit, your Windows version, the affected feature, and the potential impact. Describe the permissions or setup needed to encounter the issue and the steps to reproduce it using a local test project with synthetic data. Share only relevant, sanitized excerpts or screenshots. Omit credentials, cookies, account caches, session transcripts, and personal or customer data.

Relevant reports include unintended access across linked sessions, permission enforcement in Workflow MCP, exposure of local data, and unintended actions through the built-in browser or account integrations.

## Coordinated disclosure

Keep the report private while maintainers assess the impact and work with you on disclosure timing. Use the private advisory thread for follow-up details.

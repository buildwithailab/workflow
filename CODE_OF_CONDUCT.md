# Workflow Code of Conduct

## Community standards

Everyone is welcome to use and contribute to Workflow. Treat other participants with respect, explain disagreements without personal attacks, and give feedback that helps others improve their work. Respect people's privacy and boundaries.

Harassment, threats, discriminatory remarks, unwanted sexual attention, and sharing another person's private information without consent are unacceptable.

## Scope

These standards apply to participation in Workflow's GitHub repository, including issues, pull requests, reviews, and comments.

## Reporting

Use **Report content** on the relevant issue, pull request, or comment. Choose **Report to repository admins** when available. You can also report abuse directly to GitHub Support, including when a report concerns a maintainer. Keep conduct reports out of public project threads. [GitHub reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)

Include the link to the content and a brief description of what happened. Share only the details needed to understand the incident. Report software vulnerabilities through the [security policy](SECURITY.md).

## Enforcement

Maintainers assess reports based on the behavior, its impact, and whether it has happened before. They may warn participants, hide or remove content where GitHub allows it, lock conversations, or restrict participation. Maintainers limit sharing of report details to what is needed to review and respond.
